# 🎵 Spotify Retention Analysis

## 📌 Project Overview
This project analyzes Spotify user retention to understand listening behavior, user engagement, and factors that may influence continued platform usage. The analysis aims to identify engagement patterns and provide actionable insights to support user retention strategies.

## 🎯 Business Objectives
- Analyze user engagement and retention patterns.
- Identify factors associated with user churn.
- Understand listening behavior and user activity.
- Provide data-driven recommendations to improve user retention.

## 🛠️ Tools & Technologies
- SQL – Data querying and analysis
- Microsoft Excel – Data cleaning and preliminary analysis
- Power BI – Interactive dashboards and data visualization

## 📊 Key Analysis Areas
- User activity and engagement analysis
- Retention and churn analysis
- Listening frequency and usage patterns
- User segmentation and behavioral trends
- Retention performance indicators

## 📈 Key Performance Indicators (KPIs)
- User Retention Rate
- User Churn Rate
- Active Users
- User Engagement Rate
- Average Listening Time

## 💡 Business Recommendations
- Identify user segments with declining engagement.
- Investigate behavioral patterns associated with churn.
- Develop targeted strategies to encourage consistent listening.
- Monitor retention KPIs to evaluate improvement over time.
